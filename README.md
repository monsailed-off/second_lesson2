Яке призначення директиви #include &lt;iostream&gt;? ця бібліотека підключається для того, щоб можна було використовувати функції введення та виведення, наприклад std::cout та std::cin
им відрізняється тип int від типу double? Скільки байт вони займають у
пам&#39;яті? int потрібен для цілих чисел, занимає 4 байт, а дабл для дійсних, він занимає 8 байт
Які правила іменування змінних у C++ (що дозволено, а що заборонено)? Дозволено літри от a-z, A-Z, цифри 0-9, та знак _, _sum, counter1 (Приклад) myvar та MyVar це дві різні змінни. Заборонено починати з цифри змінну, використовувати пробіли та спеціальні символи (!, @, #, $, %,)
Поясніть роботу операторів &lt;&lt; та &gt;&gt;. << це оператор вставкі данних у потік, >> він забирає данні
Що таке інкремент і декремент? це короткі операціі для зміни значення змінної на одиницю (-+) x++ або x-- це так саме що x = x + 1 | x = x - 1
